# StaffPulse PRO (स्टाफपल्स प्रो)
### Next-Gen Corporate Employee Attendance & HR Payroll Suite

A clean, production-ready, Fortune-500 grade Corporate Attendance & HR Management Web Application built for **Companies, Startups, and Enterprises** using **React 19**, **Tailwind CSS v4**, **Native Web Audio API**, **Lucide Icons**, and **Vite**.

---

## 🚀 Clean Production Slate

All sample/demo data has been cleared. The system is ready to onboard your real company staff:

1. **Onboard Staff**: Go to **Employee Directory & Salary** → Click **"+ Add Employee"** to register your employees.
2. **Mark Daily Attendance**: Go to **Daily Attendance Roster** to mark In-Office, WFH, Half-Day, or Leave.
3. **Biometric Kiosk**: Use the **Biometric Punch Terminal** for desk or tablet clock-ins.
4. **Leave Management**: Review, approve, and auto-deduct Casual Leave (CL), Sick Leave (SL), and Privilege Leave (PL).
5. **Payroll & Reports**: View computed payable days and export payroll CSV.

*(Note: If you ever want to reload sample data for testing in the future, you can find a "Reload 30-Day Corporate Records" option under Company Settings).*
